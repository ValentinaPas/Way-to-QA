# Тест-кейсы для API (Postman)

**Цель:** Проверка корректности работы публичного API (на примере тестового сервиса ReqRes).
**Инструмент:** Postman.

| ID | Метод | Endpoint | Проверка (Описание) | Ожидаемый результат | Статус |
| :--- | :--- | :--- | :--- | :--- | :--- |
| API-01 | GET | `/api/users?page=2` | Получение списка пользователей (позитивный тест) | Статус 200 OK. В теле ответа массив данных пользователей. | Passed |
| API-02 | GET | `/api/users/2` | Получение конкретного пользователя (позитивный тест) | Статус 200 OK. В теле ответа данные пользователя с ID=2. | Passed |
| API-03 | GET | `/api/users/999` | Запрос несуществующего пользователя (негативный тест) | Статус 404 Not Found. Тело ответа пустое или содержит сообщение об ошибке. | Passed |
| API-04 | POST | `/api/users` | Создание нового пользователя (позитивный тест) | Статус 201 Created. В ответе возвращаются переданные данные (name, job) и новый ID. | Passed |
| API-05 | POST | `/api/login` | Авторизация без пароля (негативный тест) | Статус 400 Bad Request. В ответе ошибка "Missing password". | Passed |

### Пример проверки в Postman (Tests tab):
Для проверки статус-кода в Postman я использовала следующий скрипт:
```javascript
pm.test("Status code is 200", function () {
    pm.response.to.have.status(200);
});
