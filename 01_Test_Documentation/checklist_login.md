# Чек-лист: Авторизация пользователя (форма входа)

**Цель:** Проверить корректность работы формы входа в систему.
**Тестовые данные:** Логин: `test@mail.ru`, Пароль: `123456`

| № | Проверка | Ожидаемый результат | Статус |
|---|----------|---------------------|--------|
| 1 | Отображение формы входа | Форма содержит поля «Логин», «Пароль» и кнопку «Войти» | |
| 2 | Ввод валидного логина и пароля | Успешная авторизация, переход на главную страницу | |
| 3 | Ввод невалидного пароля | Появление сообщения об ошибке «Неверный логин или пароль» | |
| 4 | Пустые поля «Логин» и «Пароль» | Кнопка «Войти» неактивна ИЛИ появляется ошибка «Заполните поля» | |
| 5 | Ввод пароля (скрытие символов) | Символы пароля скрыты точками (звездочками) | |
| 6 | Функционал «Забыли пароль?» | Открывается страница/модальное окно восстановления пароля | |
| 7 | Проверка верстки (адаптивность) | Форма корректно отображается на мобильном устройстве | |

*Примечание: Чек-лист составлен в учебных целях.*
